# Посмотри в окно

Проектная работа: вёрстка интерфейса приложения «Посмотри в окно» по макету в Figma.

## Ссылка на репозиторий

https://github.com/zxcBloody/posmotri-v-okno-ad

## Что сделано

- Лейаут страницы на flexbox.
- Кастомные чекбоксы и текстовое поле поиска.
- Состояния `:hover`, `:active`, `:focus-visible` для кнопок, карточек и элементов формы.
- Карточки видео с обрезкой длинных названий и описаний.
- Позиционирование прелоадеров и блока ошибки.

## Технологии

HTML, CSS (БЭМ-именование классов). Логика приложения написана на JavaScript и дана в заготовке.

## Запуск

Откройте `index.html` в браузере. Для загрузки видео нужен доступ к внешнему серверу с данными.
